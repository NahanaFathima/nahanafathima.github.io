# Nahana Fathima — Portfolio Website

A responsive, single-page portfolio built with plain HTML and CSS.

## Before publishing
1. Open `index.html` in a text editor.
2. Replace `ADD_YOUR_LINKEDIN_URL` with your LinkedIn profile URL.
3. Replace `ADD_YOUR_EMAIL` with your professional email address.
4. Replace the generic GitHub project links with individual repository links when available.
5. Check that every project description accurately reflects your current work.

## Publish free with GitHub Pages
1. Sign in to GitHub and create a **new public repository** named exactly `NahanaFathima.github.io`.
2. Upload `index.html` to the repository's root (top-level folder).
3. Open the repository's **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then save.
6. Wait a few minutes and open: `https://NahanaFathima.github.io`

If GitHub Pages asks you to enable it, follow the prompt. The site may take a few minutes to appear.
